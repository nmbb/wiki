REGISTO DAS EXPERIÊNCIAS

O que aconteceu em cada teste.

1977–1982 · EMULAÇÃO FUNCIONAL

Altair DOS, CP/M e 86-DOS

Sete sistemas históricos executados no Open SIMH, numa VM Debian 13 do Proxmox: Altair DOS 1.0, CP/M 1.4/2.2/3.0 e 86-DOS 0.11/0.34/1.00. Os ecrãs de arranque e as listagens foram confirmados, com acesso à disquete também validado no Altair DOS.

Ver laboratório e capturas →
1981–1988 · EMULAÇÃO X86 · ESTADOS DOCUMENTADOS

IBM PC 5150, GEM, OS/2 e DR-DOS no 86Box

O IBM PC 5150 arrancou no BASIC residente em ROM (1981); o PC-DOS 1.0 ainda não foi confirmado. Foram também configuradas máquinas para GEM Desktop 1.1 (1985), OS/2 1.00 (1987) e DR-DOS 3.40 (1988), sem prova de instalação ou arranque desses sistemas. A compilação do emulador em Debian 13 está documentada separadamente.

Ver configurações, estados e capturas →
1985–1993 · VMs NO PROXMOX · DOS + WINDOWS

Windows 1.01, 2.1 e Windows for Workgroups 3.11

Os três ambientes foram executados em VMs Proxmox, instalados sobre DOS. As datas de 1985, 1988 e 1993 referem-se aos lançamentos dos Windows, não às versões de DOS utilizadas. Por exemplo, no teste do Windows 1.01 (1985) usou-se MS-DOS 3.30 (1987), posterior ao Windows. O Windows 2.1 (1988) utilizou também MS-DOS 3.30 (1987), enquanto o Windows for Workgroups 3.11 (1993) foi instalado sobre MS-DOS 6.22 (1994). Estas combinações correspondem às VMs testadas, não necessariamente às configurações originais da época. Foram observados o MS-DOS Executive, o Notepad e o Program Manager, respetivamente; a rede do 3.11 ainda não foi validada.

1996 · CONFIRMADO

Windows NT 4.0

Domínio LABNT40, controladores NT4 e estação de trabalho. Os testes de acesso à partilha Samba do Red Hat confirmaram leitura e escrita, incluindo a pasta criada a partir do Windows.

2000 · INSTALAÇÃO FALHADA

Red Hat Linux 6.2

O instalador Anaconda terminou com uma exceção associada a getCompsList(). Não se concluiu a instalação nem se identificou uma causa definitiva.

Ver Linux Retro →
2000 · CONFIRMADO

Windows 2000

Instalação e autenticação verificadas. A VM foi usada para abrir uma partilha pessoal do Samba no SuSE Linux 9.0. A validação de permissões da pasta COMUM ficou incompleta.

Ver teste Samba →
2001 · FUNCIONAL

Red Hat Linux 7.1

Kernel 2.4.2-2 e Samba 2.0.7. Ligação através da vmbr70, correção da resolução de hostname e pasta ALUNOS acessível com escrita a partir do Windows NT 4.0.

Ver capturas e comandos →
2001 · INSTALAÇÃO FALHADA

Caldera OpenLinux Server 3.1

Detetou dispositivos PCI, CD-ROM e placa Ethernet, mas o LIZARD apresentou problemas e ficou bloqueado ao preparar o particionamento. A instalação não foi concluída.

2003 · PARCIALMENTE VALIDADO

SuSE Linux 9.0

Instalação concluída pelo YaST, rede virtual vmbr71 e SSH verificados. Samba 2.2.8a respondeu ao Windows 2000. A pasta COMUM apresentou NT_STATUS_BAD_NETWORK_NAME.

Windows Server 2008 R2
