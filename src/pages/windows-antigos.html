O contexto: primeiro o DOS, depois o Windows

Nestas experiências não se instalou um Windows moderno que inicia autonomamente: preparou-se um ambiente DOS dentro de máquinas virtuais no Proxmox e executou-se o instalador da versão de Windows correspondente. Esta sequência ilustra os primeiros ambientes gráficos da Microsoft, que dependiam de uma base DOS.

Critério de documentação: as imagens comprovam o que aparece no ecrã — aplicações abertas, assistentes de instalação e ambiente gráfico. Não se deduzem configurações exatas de processador, memória, discos ou drivers que não estejam demonstradas. A numeração das VMs destes três testes não está indicada nas capturas.

Sequência geral de trabalho

  1. Criar uma máquina virtual e preparar um disco com DOS utilizável.
  2. Apresentar as disquetes de instalação ao sistema convidado.
  3. Executar o programa de instalação do Windows a partir do DOS.
  4. Trocar as disquetes quando solicitado pelo instalador, concluir a configuração e iniciar o ambiente gráfico.
  5. Verificar a interface e abrir uma aplicação para documentar a execução.

Esta sequência resume o método usado; não é um registo de comandos individualizado de cada VM.

1985 · Windows 1.01

Windows 1.01 — MS-DOS Executive

O Windows 1.x introduziu um ambiente gráfico que corria sobre DOS. A captura enviada mostra o MS-DOS Executive, com acesso às unidades e listagem de ficheiros de sistema e aplicações. É uma prova visual de que o ambiente gráfico desta experiência foi iniciado e pode apresentar o seu gestor de ficheiros.

Comparado com as versões seguintes, o ambiente é mais simples: os programas e ficheiros são lançados a partir do Executive, sem o Program Manager que surgiria mais tarde.

1988 · Windows 2.1

Windows 2.1 — janelas e Notepad

O segundo teste mostra o Windows 2.1 já dentro do seu ambiente gráfico, com o Notepad aberto e texto introduzido. A janela do MS-DOS Executive encontra-se atrás, permitindo observar a sobreposição de janelas, uma diferença visível em relação à experiência com o Windows 1.x.

Resultado observado: ambiente gráfico iniciado, aplicação aberta e interação no editor de texto.

1993 · Windows for Workgroups 3.11

Windows for Workgroups 3.11 — instalação por disquetes

A experiência com o Windows for Workgroups 3.11 evidencia o processo de instalação característico da época. O instalador é executado a partir do DOS e pede sucessivamente as disquetes necessárias, copiando os componentes do ambiente gráfico para o disco virtual.

Depois da instalação, a captura seguinte mostra o Program Manager aberto, com o grupo Main e os restantes grupos de aplicações. A presença do ambiente gráfico confirma um resultado mais avançado do que um simples ecrã de instalação.

Estado confirmado pelas imagens: instalação realizada até ao arranque gráfico e Program Manager acessível. A funcionalidade de rede, partilha de ficheiros ou ligação a domínio não está demonstrada nestas capturas e fica por testar/documentar.
