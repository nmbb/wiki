WIKI TÉCNICA — estrutura para alojar em /wiki/

Colocar o conteúdo DESTA pasta diretamente na pasta pública /wiki/ do servidor.
Não criar uma segunda pasta wiki/ dentro dela.

Entrada principal: /wiki/index.html (normalmente acessível em /wiki/)
Índice de artigos: /wiki/artigos.html
Artigos: /wiki/pfsense.html, /wiki/proxmox.html, etc.
Recursos: /wiki/assets/css/ e /wiki/assets/img/

Para testar offline, abrir index.html. Os links internos são relativos e não dependem de um domínio específico.
